	            2.ABSTRACT
The rapid expansion of social media in India has led to an explosion of code-mixed toxicity, presenting a "Trinity of Challenges" for automated moderation: deep transformer models are too computationally expensive for real-time streams, lightweight models lack the contextual awareness to detect sarcasm or emotional nuance, and traditional classifiers act as opaque "black boxes."
To address this, we implement a highly optimized, multilingual cyberbullying detection system utilizing Multi-Teacher Knowledge Distillation (MTKD). Our approach compresses an ensemble of heavy transformers (mBERT, XLM-R, and MuRIL) into a 0.91 MB XGBoost Student model utilizing a 21,384-dimensional feature space.
To regain contextual intelligence, the student model is augmented by a 4-Rule Hybrid Fusion Engine that dynamically calibrates threat levels using auxiliary BiGRU (Sarcasm) and XLM-R (Emotion) networks. Finally, to ensure operational transparency without sacrificing processing speed, we introduce a novel 5-Stage Short-Circuit Explainable AI (XAI) pipeline that bypasses computationally expensive SHAP calculations using O(1) dictionary heuristics.
Evaluated on a 3,272-sample multilingual social media dataset spanning 14 languages, our system achieves sub-second inference latency (~300ms) and massive model compression (~1000x) while achieving a robust F1-score of 0.93, proving its efficacy for enterprise edge-device deployment.

Week 1: July 14 – July 20, 2025
	Title: Project Initiation, Problem Formulation, and Deep Literature Survey		
	
1) Formulated the core problem statement: The catastrophic failure of standard NLP models on Indian 
code-mixed languages (Hinglish/Tanglish) and their inability to process real-time social media streams
due to latency bottlenecks.
2) Conducted an exhaustive literature survey reviewing over 20+ IEEE and ACM research papers focusing 
on Multi-Teacher Knowledge Distillation (MTKD), Affective Computing, and Large Transformer
architectures like mBERT, XLM-R, and MuRIL.
3) Established the 14+ native Indian language scope and engineered the overarching 4-Phase system 
architecture: Data Engineering (Phase 1), Teacher Distillation (Phase 2), Context Fusion (Phase 3), and
Full-Stack Deployment (Phase 4).
4) Presented the initial synopsis to the internal review committee and secured formal approval to proceed 
with the proposed architecture.
Week 2: July 21 – July 27, 2025
	Title: Synthetic Seed Generation &amp; Linguistic Ontology Construction		
	
1) Initiated Phase 1 Data Engineering. Utilized a Large Language Model (LLM) as a linguistic knowledge 
base to generate a foundational ontology of 15,000+ toxic English seed keywords. These were rigorously
categorized by threat type (e.g., appearance_body_shaming, direct_intelligence_insults).
2) Engineered build_keywords_database.py utilizing the deep_translator library to programmatically 
translate the English base into 12 native Indian languages (Marathi, Bengali, Tamil, Telugu, etc.) via the
Google Translate API.
3) Developed custom algorithmic mixing logic to mathematically blend the top 100 English and top 100 
		
translated Hindi Romanized words. This successfully generated a synthetic, highly accurate "Hinglish"
dictionary, capturing real-world code-mixed vernacular.
4) Saved outputs into language-specific JSON files and a complete_multilingual_database.json file for 
systematic loading.
Week 3: July 28 – August 03, 2025
	Title: API Configuration and Round-Robin Collector Design		
	
1) Configured enterprise developer accounts and securely generated authentication keys for Twitter (X) 
via Tweepy, Reddit via PRAW, and YouTube via the Google API Client. Stored all credentials securely in
config.py using .env environment variables.
2) Designed the start_data_collection.py script to execute a highly optimized round-robin harvesting 
sequence across the three platforms, preventing any single API from facing rate-limit bans.
3) Programmed dynamic batch processing capabilities. The script was engineered to query the social 
media APIs using chunks of exactly 10 translated keywords per language, employing exponential backoff
and sleep functions to ensure uninterrupted data streams.
Week 4: August 04 – August 10, 2025
	Title: Raw Data Extraction and Multilingual Harvesting		
	
1) Executed the heavy collection pipelines (reddit_collector.py, twitter_collector.py, youtube_collector.py) 
across all target platforms.
2) For Reddit, extracted both hot submission selftext and nested comments. For Twitter, utilized the recent 
search endpoint with boolean queries filtering out retweets (-is:retweet). For YouTube, extracted raw
plainText comments from highly volatile video topics.
3)Harvested an initial raw dataset of 5,000 to 7,000 unstructured, noisy, and highly contextual User-
Generated Content (UGC) rows.
4) Engineered a local data lake, saving the raw outputs sequentially into nested 
data/raw/{platform}/{language}/ directories.
Week 5: August 11 – August 17, 2025
	Title:  Data Sanitization and Weak Supervision Labeling		
1) Developed run_preprocessing_final_fixed.py to recursively aggregate the thousands of raw CSV files 
from the local data lake.
2) Engineered aggressive text sanitization routines using Python's re module. Successfully stripped web 
URLs, HTML tags, and @mentions while strictly preserving native Unicode characters (e.g., Devanagari)
and contextual emojis necessary for sentiment analysis.
3) Implemented a deterministic "Weak Supervision" pipeline. Converted the massive multilingual 
keyword JSONs into highly optimized Regex patterns. The script programmatically scanned the cleaned
text and assigned binary labels (1=Toxic, 0=Safe) based on exact pattern matches, entirely eliminating the
bottleneck of human annotator bias.
Week 6: August 18 – August 24, 2025
		Title: 	Dataset Finalization and Stratified Splitting	
1) Executed strict deduplication and morphological noise-removal protocols on the automatically labeled 
data to prevent model overfitting on identical spam messages.
2) Finalized a highly refined corpus of exactly *3,272 high-quality, cleaned samples* across all platforms 
(Reddit: ~1,800, YouTube: ~1,000, Twitter: ~472).
3) Performed a mathematically rigorous stratified split using sklearn.model_selection.train_test_split (70% 
Train, 15% Validation, 15% Test). This preserved exact class imbalances across all 14 languages.
4) Exported the final multilingual_dataset.csv and compiled the comprehensive dataset_stats.json for 
documentation.
Week 7: August 25 – August 31, 2025
		Title: 	Baseline Model Benchmarking &amp; Statistical EDA	
1) Trained an initial, undistilled Baseline XGBoost model (01_baseline_xgboost.py) using basic 
stylometric features (word count, uppercase ratio) and rudimentary TF-IDF to establish a "Performance
Floor" for the project.
2) Developed 01_baseline_analysis.py to automatically extract confusion matrices, ROC-AUC curves, and 
classification reports using matplotlib and seaborn.
